# مبادرة توثيق إجراءات التشغيل القياسية (SOP) — عمادة القبول والتسجيل

**جامعة أم القرى · وكالة العمادة للتطوير**

---

## 1. ما هذه المبادرة؟

مبادرة لتوثيق إجراءات التشغيل القياسية (Standard Operating Procedures) في أقسام عمادة القبول والتسجيل، بحيث يكون لكل خدمة تقدمها العمادة إجراءٌ مكتوبٌ موحّد الشكل والترميز، يوضّح خطواته ومدده ومسؤولياته واستثناءاته ومؤشرات قياسه.

**الهدف:** تحويل المعرفة التشغيلية من معرفة شخصية لدى الموظفين إلى أصل مؤسسي موثّق — يقصّر زمن تدريب الموظف الجديد، ويوحّد جودة الخدمة، ويوفّر الشواهد المطلوبة للجودة والاعتماد المؤسسي، ويكون الأساس الذي تُبنى عليه الأتمتة لاحقاً.

**قائد المبادرة:** وكيل العمادة للتطوير — د. أحمد الهندي
**راعي المبادرة:** عميد القبول والتسجيل

**النطاق النهائي:** ثمانية أقسام قائمة + وحدة السجلات الأكاديمية والتحقق (ARV) المقترحة.

---

## 2. المرحلة الحالية: مشروع إرشادي واحد

> **العمل الجاري الآن محصور في قسم الطلبة الدوليين فقط**، داخل مجلد `int-pilot/`.

القرار المتخذ هو إكمال قسم واحد من أوله إلى آخره — من الحصر حتى اعتماد الإجراءات بالإصدار 1.0 — قبل فتح أي قسم آخر. الغرض من ذلك:

1. بناء **قصة نجاح** ملموسة تُعرض على بقية رؤساء الأقسام بدل الشرح النظري.
2. استخلاص **نموذج عمل (use case)** مجرَّب: كم يستغرق القسم؟ ما الذي يعطّل؟ ما الذي يمكن اختصاره؟
3. تنقيح القالب والمنهجية على حالة حقيقية قبل التوسّع.

لذلك **لن تجد في هذا المستودع مجلدات لأقسام أخرى**، ولن تُنشأ إلا بعد اكتمال المشروع الإرشادي.

## 3. خريطة المستودع (مستويان)

المستودع منظَّم على مستويين: **مستوى المبادرة** في الجذر، و**مستوى المشروع** في مجلد لكل قسم.

```
dar-sop/
├── README.md                     ← هذا الملف
├── 00-المبادرة/                  ← الوثائق الأم للمبادرة كلها
│   ├── المرفق 1 — خطة الإطلاق المرحلية
│   ├── المرفق 2 — القالب الموحد لإجراء التشغيل القياسي
│   └── المرفق 3 — فوائد ومبررات المشروع
├── 01-مراسلات-المبادرة/          ← الخطابات على مستوى العمادة
│   └── خطاب رفع حزمة الاعتماد للعميد (docx + pdf)
└── int-pilot/                    ← المشروع الإرشادي: قسم الطلبة الدوليين
    ├── 00-الحوكمة/               ← الميثاق، سجل القرارات، سجل الدروس المستفادة
    ├── 01-المراسلات/             ← خطابات القسم وإيميلاته (التاريخ-الجهة-الموضوع)
    ├── 02-الحصر/                 ← سجل حصر العمليات وإصداراته
    ├── 03-الجلسات/               ← أوراق الجلسات ومحاضرها
    ├── 04-الإجراءات/             ← مجلد لكل إجراء برمزه (DAR-INT-001 … 011)
    ├── 05-الدليل-الأصلي/         ← الدليل الإجرائي القديم للقسم (مرجعية)
    ├── 06-الأدوات/               ← الجدول الزمني، قائمة المهام، أدوات المتابعة
    └── 07-الفهرس/                ← فهرس إجراءات القسم وحالاتها
```

**قاعدة التوسّع:** كل قسم جديد يصبح مجلداً شقيقاً لـ `int-pilot/` بالبنية الداخلية نفسها (00 إلى 07). وثائق المبادرة الأم لا تتكرر داخل مجلدات الأقسام.

**قاعدة الحفظ:** لا يُحذف أي ملف من هذا المستودع. النسخ القديمة أو المكرّرة تُنقل إلى مجلد `_أرشيف/` داخل موقعها نفسه.

## 4. دليل الترميز

كل إجراء يحمل رمزاً فريداً بالصيغة:

```
DAR-[رمز القسم]-[رقم متسلسل من ثلاث خانات]
```

مثال: `DAR-INT-001` = عمادة القبول والتسجيل · قسم الطلبة الدوليين · الإجراء الأول.

### رموز الأقسام

| الرمز | القسم |
|---|---|
| REG | التسجيل |
| ADM | القبول |
| RES | النتائج |
| CSD | خدمة المستفيدين |
| GRD | التخرج |
| ACA | الشؤون الأكاديمية |
| PLN | الخطط |
| INT | الطلبة الدوليون |
| ARV | السجلات الأكاديمية والتحقق (وحدة مقترحة) |

> الأقسام عدا INT مدرجة هنا لحجز الرموز فقط — لم يبدأ العمل عليها.

كما تُستخدم رموز على مستوى المبادرة لوثائقها الأم: `DAR-PLAN-SOP-001` (خطة الإطلاق)، `DAR-SOP-TMP-001` (القالب الموحد)، `DAR-SOP-BEN-001` (وثيقة الفوائد).

## 5. دورة الإصدارات

| الإصدار | المعنى |
|---|---|
| **0.9 — مسودة** | صاغها فريق المشروع من الدليل القائم أو من جلسة الحصر، ولم يراجعها القسم بعد. |
| **قيد المراجعة** | بيد رئيس القسم وصاحب العملية للتحقق من مطابقتها للواقع. |
| **1.0 — معتمد** | أُقرّت بعد المراجعة ورُفعت للعميد للاعتماد. هي النسخة المعمول بها. |

التعديلات اللاحقة ترفع الرقم (1.1، 1.2 …)، والتغيير الجوهري في الإجراء يرفعه إلى 2.0. اسم الملف يحمل رقم الإصدار دائماً، مثال: `سجل حصر العمليات — INT v1.0.xlsx`.

**الإجراءات الموسمية** يُضاف في جدول ضبط وثيقتها سطر «التوقيت في التقويم الأكاديمي».

## 6. مسارات التوثيق الثلاثة

يُسأل كل رئيس قسم سؤالاً واحداً أولاً: **هل لديكم دليل إجرائي قائم؟** والجواب يحدد المسار:

| المسار | الحالة | ما يُعمل |
|---|---|---|
| **(أ)** | لدى القسم دليل إجرائي قائم | **ترقية:** إعادة تجميع مهامه إلى خدمات SOP بطبقتين (الإجراء الخدمي + تعليمات الشاشات كملحق)، ثم جلسة فجوات قصيرة للمدد والاستثناءات والمؤشرات. |
| **(ب)** | لا يوجد توثيق | **حصر من الصفر:** جلسة حصر مع رئيس القسم (زوايا ← مهام) ← سجل حصر ← ورقة جلسة ← تعبئة القالب. |
| **(ج)** | وحدة ARV | مواءمة وثيقتها الجاهزة مع القالب الموحد فقط. |

**قسم الطلبة الدوليين على المسار (أ)** — دليله القائم أُعيد تجميعه إلى 11 إجراءً خدمياً بالرموز DAR-INT-001 حتى DAR-INT-011.
